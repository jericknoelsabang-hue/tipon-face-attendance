DEVICE PREFERENCES

Settings & Offline

Prepare the device for offline use, install on your phone, and safeguard local data.

Organization Connection

The Google Apps Script connection is configured once in GitHub Pages. No Netlify account, Netlify function, or gateway key is required on this device.

Offline AI Package

On the first setup, connect to the internet once to cache the face-recognition models. The Excel export engine is already included with this app. After downloading, the terminal can operate offline on this device.

Not downloaded yet

Install on Your Phone

Open the published GitHub Pages site. On Android, use Chrome and choose Install app. On iPhone, use Safari → Share → Add to Home Screen.

Camera and GPS require HTTPS or localhost. Opening index.html directly will not work.

Encrypted Device Backup

Save your locally enrolled members, facial templates, GPS work locations and attendance. Use a strong backup passphrase; keep the file private.

Backups are essential: clearing browser data removes local records.

Only Administrators can export or restore organization backups.

Security & Limitations

Role checks are enforced by the server. Approved accounts have a password-encrypted offline lease. This pilot uses basic interactive liveness, not certified anti-spoofing. Hardware and GPS can be spoofed. Complete security and privacy testing before payroll use.

Use an approved member privacy notice and retention policy. Photos are not stored; encrypted numerical face templates synchronize to authorized terminals. Do not treat face/GPS results as independently verified payroll evidence.
